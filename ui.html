A second clip read frame-for-frame beside the source, whose brightness becomes the alpha: white keeps the source pixel, black makes it transparent, grey keeps the edge soft. Nothing loads on the GPU — the model above is not run — so the result is exactly as good as the mask. For a clip the model gets wrong, or one you rotoscoped yourself.
Start / End / Frame step apply to the mask too, and it must have at least as many frames in that range as the source; a mask at another resolution is resized to it. Hard edge is off by default because a hand-drawn edge is the mask's whole advantage — turn it on for a mask an encoder has muddied, or one that is only black and white but arrived soft.
3 · Matte repair
Clear leaked backdrop (border flood-fill)
Only regions touching the frame border
Topological, not tonal: the backdrop touches the frame border, the subject's own dark pixels are enclosed by its body. Set the threshold just above the backdrop's own noise floor.
Unticked it stops being topological: every near-black pixel goes, enclosed ones included. That reaches backdrop the subject cut off from the border — inside a handle, between an arm and the body — and eats the subject's own dark parts with it, an outline or a boot. Which of those is worse is yours to decide, so the box is on.
Clear chroma-key edge leak (colour key)
Also clear key-coloured regions touching the frame border
The other half of the same job, and the one a green screen needs. It is tonal instead of topological — the flood fill reaches only backdrop connected to the frame border, so a green edge hugging the subject is enclosed by it and never seen. Pixels within the tolerance of the picked colour (straight RGB distance, 0 = exact match) that sit within 6 px of transparency lose their alpha. Reading the clip seeds the picker with the clip's own border colour; the tolerance is the destructive dial. This pass is for a chroma backdrop though — on a near-black one the flood fill above is the better tool, because it walks the border in instead of cutting a 6 px ring off the contour.
The box ADDS the same topological test on top of the band: every key-coloured region reachable from the frame border goes too — a slab of backdrop left along a frame edge, opaque and deeper than the band, is the leak it catches. Ticking it can only clean more; unticked, the key is the 6 px band alone. An enclosed patch of the key colour — a subject painted like the backdrop — is never touched in either state.
The pass also takes the colour out of the spill it cannot match. Backdrop light bleeding into the outline leaves dark green pixels (0,50,0) that are 200+ away from any green key, so no tolerance reaches them — at 255 the subject's own mid-greys are 205 away and go with them, which is why raising the tolerance eats the sprite and still shows green. Green is clamped to the larger of red and blue there instead: the outline turns black, nothing is deleted and no alpha changes. The despill reaches the 6 px band around full transparency plus every semi-transparent pixel, wherever it sits — measured on real sheets the leftover spill is soft alpha up to 21 px deep, which a fixed band misses. Only fully opaque pixels are reachable through the band, so a subject's interior saturation is never touched. Raise the tolerance if green still shows as a grey rim instead.
4 · Sheet layout
Force square cells
A grid must be full: columns × rows = frame count, or engines play the empty cells as blank frames. The column list is therefore the divisors of the frame count, and the auto choice minimises the largest sheet dimension.
5 · Playback
